# Application Services

Self-hosted applications that combine web services, databases, background
workers, authentication, and other homelab integrations.

## Services

| Service | Purpose |
|---|---|
| [Mealie](mealie/) | Recipe management and meal planning backed by PostgreSQL. |
| [Wardrowbe](wardrowbe/) | Multi-container wardrobe application with PostgreSQL, Redis, OIDC, background workers, and local AI integration. |

## Skills Demonstrated

- Multi-container application architecture
- PostgreSQL and Redis integration
- Health-check based dependencies
- External Docker networks
- Authentication configuration
- Background workers
- Local AI service integration
- Environment-based secret management
